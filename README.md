# WEDE2050_POE
Developing resilient, autonomous space robotics for deep space research.

## Project overview
**Spacebotics** is a website about a fictional robotics organisation that builds and develops robotics aimed at assisting in future lunar and solar missions.

## Core Technologies
HTML5, External CSS styling, and JavaScript for interactive, responsive web design.

## Layout & Interactive Features
* **CSS Box Model & Flexbox Layouts:** Structured page layouts and a modern flexbox-aligned header configuration.
* **Interactive Navigation Menu:** Dropdown selector components for filtering robotic vehicles seamlessly.
* **Multimedia Lightbox Gallery:** JavaScript-driven image overlay modal allows users to sequentially scroll and view full-sized rover components.
* **Dynamic Client-Side Search Engine:** Real-time product search functionality on the Merch page to filter titles instantly (e.g., typing 'shirt').
* **Asynchronous Inquiry Forms:** Secure contact forms integrated with Web3Forms API and robust, localized client-side constraint validation.
* **Real-Time Live Clock:** Background runtime script that injects a ticking local timestamp layout into the shared footer component.
